Privacy policy

Last updated: September 29, 2026.

drive-youtube-sync is a personal tool used only by its developer on their own computer.

What data it accesses

  • Google Drive (read-only): lists and downloads video files from specific folders the user chooses.
  • YouTube: uploads those videos to the user's own channel and adds them to the user's own playlists.

How data is stored

All data stays on the user's own computer: the Google sign-in token, a list of which files were already uploaded, and local copies of the videos. Nothing is sent to any server operated by the developer, and no data is sold, shared, or used for advertising.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
